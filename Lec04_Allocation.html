Portfolio Optimization

Efficient Frontier: An Optimization Problem

① MAX Return for Given Risk

Objective
maxw w′μ
Subject to
w′Σw ≤ σ̄² (risk budget)
Σwᵢ = 1 (fully invested)
wᵢ ≥ 0 (long-only)
Fix σ̄, maximize E[r]. Sweep σ̄ from σMVP upward to trace the frontier.

② MIN Risk for Given Return

Objective
minw w′Σw
Subject to
w′μ ≥ r̄ (return target)
Σwᵢ = 1 (fully invested)
wᵢ ≥ 0 (long-only)
Fix r̄, minimize σ. Sweep r̄ from min to max to trace the same frontier.
Key insight: Both formulations trace the same curve. The solution is a Quadratic Program (QP) — solved by scipy, CVXPY, Excel Solver, or any financial optimizer.

Risk-Adjusted Performance

The Sharpe Ratio

SR = (E[rp] − rf) / σp
What it measures: how much excess return (above the risk-free rate) you earn per unit of risk.

A higher Sharpe ratio means you are being better compensated for each unit of risk taken.

Interpreting SR
SR < 0: portfolio return below risk-free rate
0 < SR < 0.25: poor compensation for risk
0.25–0.50: decent risk-adjusted return
SR > 0.50: excellent (rare in practice)
Building Blocks

The Risk-Free Asset

What is the Risk-Free Rate?
The risk-free rate is the return on an asset with zero default risk and zero volatility (σ = 0).

Common proxies:
• U.S. 3-Month Treasury Bill
• Overnight SOFR rate
• 1-year Treasury Note

Current rate (Sept 2026):
rf = 4.3%
Why it matters for portfolios
Adding a risk-free asset to the opportunity set linearizes the frontier.
Instead of picking a point on the curved EF, investors mix:
• Fraction w in a risky portfolio
• Fraction (1−w) in the risk-free asset

The combination lies on a straight line from rf → risky portfolio.

Summary

What We Learned

Diversification always helps when ρ < +1
The Efficient Frontier is the set of portfolios with max E[r] for each σ
Optimization (QP) finds the exact frontier weights
The Sharpe Ratio measures return per unit of risk
Adding a risk-free asset creates the Capital Allocation Line
The Tangency Portfolio maximizes the Sharpe Ratio
Real investors mix rf and tangency to hit their target risk
Key insight: Diversification is free — but the right combination matters. The tangency portfolio maximizes the Sharpe ratio for this universe of assets. Most investors hold something between the risk-free asset and the tangency portfolio.
